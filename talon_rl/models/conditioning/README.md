# Conditioning

<!-- nav:start -->
[TALON package](../../README.md) · [Models](../README.md)
<!-- nav:end -->


Preference-conditioning mechanisms built on the shared foundations.

- `feature_film.py`: feature-wise FiLM conditioning from the three-objective foundation.
- `single_site_film.py`: single-site FiLM extension of the preference-embedding foundation.
- `residual_experts.py`: preference-gated residual experts.
- `hypernetwork.py`: low-rank preference-conditioned hypernetwork.
- `private_residual.py`: coefficient-generated private residual modules.
- `policy_family.py`: generated continuous policy-family parameterization.
