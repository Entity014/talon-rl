## Purpose

Thesis-facing synthesis and production documents.

## Scope

These files should cite retained contracts/verdicts rather than becoming a second source of experimental truth.

## Research progression

1. method chapter describes the retained pipeline
2. results chapter reports accepted evidence
3. discussion interprets implications and limitations
4. conclusion states the thesis-level contribution
5. appendix preserves traceability
