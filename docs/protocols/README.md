## Purpose

Operational procedures that must be run consistently.

## Scope

Protocols differ from research contracts: they specify how to execute or freeze a workflow, while contracts specify what scientific question must pass.

## Research progression

1. freeze procedure
2. execute unchanged
3. store provenance
4. use the resulting evidence in a contract/verdict chain

- evaluation/ — 1 documents
- freeze/ — 1 documents
- pipeline/ — 1 documents

## Maintenance

Keep provenance-bearing experiment IDs in document filenames. Move documents by role/domain and update repository references when paths change.
