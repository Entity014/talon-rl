## Purpose

Documents that formally close a research branch or choose between methods.

## Scope

Closures consolidate several verdicts into a branch-level decision so later work does not repeatedly reopen resolved alternatives.

## Research progression

1. collect relevant verdicts
2. state what is ruled out
3. state what remains active
4. record the next permitted research branch

## Subfolders

- method_selection/ — 2 documents
- phase_closures/ — 3 documents
- synthesis/ — 1 documents

## Maintenance

Keep provenance-bearing experiment IDs in document filenames. Move documents by role/domain and update repository references when paths change.
