## Purpose

Contracts for cross-cutting causal and semantic diagnostics.

## Scope

These audits investigate whether observed failures come from objective definition, state manifold coverage, trajectory information, update effects, visitation, or collapse mechanisms rather than from a single architecture.

## Research progression

1. define the suspected failure mechanism
2. construct matched or held-out diagnostic conditions
3. measure causal or informational separation
4. retain only explanations supported across the diagnostic gate
