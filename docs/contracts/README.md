## Purpose

Pre-registered research questions, invariants, gates, and evaluation criteria.

## Scope

Contracts should describe what must be measured before results are known. They should not be rewritten to fit later outcomes.

## Research progression

1. define treatment and control
2. freeze metrics and gates
3. run the corresponding experiment
4. compare evidence against the contract
5. record the conclusion under verdicts
