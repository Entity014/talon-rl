## Purpose

Formal evaluation contracts that define final task-level scoring or acceptance gates.

## Scope

Use this folder when evaluation criteria themselves are pre-registered and are not merely implementation protocols.

## Research progression

1. freeze evaluation population and metrics
2. run evaluation unchanged
3. record retained result under verdicts or thesis synthesis

## Maintenance

Keep provenance-bearing experiment IDs in document filenames. Move documents by role/domain and update repository references when paths change.
